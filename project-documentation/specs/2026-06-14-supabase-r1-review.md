## Accepted residuals (per spec / deferred — NOT fixed)

- **anon cross-tenant submission write** (anon can set any `tenant_id` on a lead). Spec/brief-sanctioned (`tenant_id is not null`); pure RLS can't know the request's origin. Commented in the migration; **R6** should move the contact form to a server route using the service-role key and then drop the anon insert.
- **anon media metadata read is tenant-agnostic** (`using(true)`). Per spec §5/§6 (media is public marketing imagery; binaries are public-URL reachable anyway). Documented.
- **Storage downloads rely on `bucket.public = true`** (no SELECT policy for reads). Correct for a public bucket; commented that nothing sensitive may go in it.
- **First-admin bootstrap is service-role-only** (chicken-and-egg). Standard; documented as an onboarding step.
- **`media.bucket_path` not constrained to the tenant segment.** Low/integrity-smell; deferred to R3 (uploader convention) to avoid over-constraining the path scheme now.
